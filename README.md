# Server Language Changer (SLC)

Simple server-side mod for Fabric that allows you set language of server. This mod is useless, if your server's community is primarily English-speaking and you don't use some mods which adds bridges between Minecraft and other chats (such as Discord or Telegram).

All downloaded Minecraft language files are stored in `server_languages/` folder, along with `_current.txt` file.

Supports Server Translations API.

# Usage

Just type `/slc <lang_code>` in console or in-game chat to set language. `lang_code` can be any valid Minecraft language code. Examples: `en_us`, `uk_ua`, `ja_jp`, `en_gb`.
